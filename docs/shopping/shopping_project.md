# 쇼핑 관리 (`/shopping`)

## 개요

구매 기록과 참고 자료를 한 곳에서 관리하는 화면.
상단 모드 토글로 **구매 목록**과 **참고 자료**를 전환하며, 각각 좌측 목록 + 우측 상세의 2-panel 레이아웃으로 구성된다.

---

## 화면 구조

```
/shopping
├── 모드 토글: [구매 목록] [참고 자료]
│
├── [구매 목록] 모드
│   ├── 필터 바: [전체] [국내] [국외] [휴대폰] [노트북]
│   └── 2-panel
│       ├── 좌측: 최근 30개 목록 (구매일자 / 제품명 / 구입가격 / 카테고리 배지)
│       └── 우측: 상세 (구매일자·제품명·결제수단·제품가격·구입가격·구매처·내용·파일 목록)
│           - 추가 / 편집 / 삭제 버튼
│
└── [참고 자료] 모드
    └── 2-panel
        ├── 좌측: 최근 30개 목록 (제목 / 카테고리 배지 / 등록일)
        └── 우측: 상세 (제목·카테고리·링크·내용·파일 목록)
            - 추가 / 편집 / 삭제 버튼
```

---

## 기능 목록

### 구매 목록

| 기능 | 설명 |
|------|------|
| 카테고리 필터 | 전체 / 국내 / 국외 / 휴대폰 / 노트북 |
| 목록 조회 | 최근 30건, 구매일자 내림차순 |
| 상세 조회 | 목록 선택 시 우측에 전체 항목 표시 |
| 추가 | 우측 패널에서 폼 입력 후 저장 |
| 편집 | 상세 패널에서 인라인 편집 |
| 삭제 | 확인 후 삭제 (첨부파일 Supabase Storage에서도 삭제) |
| 이미지 붙여넣기 | 내용 영역 또는 파일 영역에서 Ctrl+V → Supabase Storage 업로드 |
| 첨부파일 업로드 | 파일 선택 → `/api/shopping/upload` → Supabase Storage |
| 첨부파일 보기/삭제 | 상세 패널 하단 파일 목록 |

### 참고 자료

| 기능 | 설명 |
|------|------|
| 목록 조회 | 최근 30건, 등록일 내림차순 |
| 상세 조회 | 목록 선택 시 우측에 표시 |
| 추가 / 편집 / 삭제 | 구매 목록과 동일 |
| 링크 | URL 필드, 클릭 시 새 탭 열기 |
| 이미지 붙여넣기 / 첨부파일 | 구매 목록과 동일 (ref_type = 'ref') |
