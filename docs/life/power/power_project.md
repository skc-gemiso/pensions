# 전기요금 관리 (`/life/power`)

## 개요

매달 검침 사용량을 입력하면 계절별 누진 요금·부가항목·할인을 계산해 청구요금을 산출하고,
여름철 과사용을 막기 위해 일별 사용량을 추적하는 화면. 기존 엑셀 관리를 대체한다.

- 경로: `/life/power` (생활 > 전기요금)
- 기술 명세: [power_task.md](power_task.md)

---

## 화면 구조 — 탭 3개

```
┌ 월별 청구 ─┬ 일별 사용량 ─┬ 요금표 관리 ┐
```

### 1. 월별 청구 — 좁은 목록(좌) + 넓은 계산 내역(우)

목록은 고르는 용도라 **300px 고정**으로 좁히고, 남는 폭을 전부 계산 내역에 준다.

```
┌ 목록 300px ────────┐ ┌ 계산 내역 (나머지 전부) ─────────────────────┐
│▎2026-07   19,100원 │ │ 2026년 7월  06.22~07.21 · 30일    19,100원   │
│ 288.0kWh 복지-20,000│ ├──────────────┬──────────────┬───────────────┤
│                    │ │ 사용량 288.0 │ 전기요금계   │ 할인 합계     │
│ 2026-06   22,400원 │ ├──────────────┴──────────────┴───────────────┤
│ 272.0kWh 복지-18,709│ │ 계절 일수 · 총 30일   │ 구간 안분 내역      │
│                    │ │ [기타9][여름21]       │ 기타 86kWh 2구간    │
│ 2026-05   17,830원 │ │ [   하계 30   ]       │ 여름 202kWh 1구간   │
│ …                  │ ├───────────────────────┼─────────────────────┤
│                    │ │ 요금 구성             │ 할인 · 세금         │
│                    │ │ 기본요금       889원  │ 복지할인 -20,000원  │
│                    │ │ 전력량요금  32,034원  │ …                   │
│                    │ │ …                     │ 청구금액  19,100원  │
└────────────────────┘ └─────────────────────────────────────────────┘
```

목록 항목은 **요금월 · 청구요금**을 크게, **사용량 · 복지할인 · 하계/동계 할인**을 아래 작은 줄로 보여준다.
수정·삭제 버튼은 마우스를 올렸을 때만 나타나 평소에는 숫자에 집중된다.
목록이 길어지면 세로 스크롤되고, 계산 내역은 `sticky` 로 화면에 남는다.

**화면을 열면 가장 최근 청구가 자동 선택**되고, 선택 항목은 왼쪽 파란 막대와 배경으로 표시된다.
선택한 청구를 삭제하면 다시 최신 건이 선택된다.

계산 내역은 **한전 고지서와 같은 순서·명칭**으로 보여준다.

| 영역 | 내용 |
|------|------|
| 헤더 | 요금월 · 사용기간 · 총일수 · **청구금액** |
| 핵심 수치 3칸 | 사용량 / 전기요금계 / 할인 합계 |
| 계절 일수 (좌) | 막대 2줄 — 전력량 요금 계절(여름 7~8월)과 복지할인 계절(하계 6~8월)을 따로 표시 |
| 구간 안분 내역 (우) | 계절별 안분 사용량 · 1구간 상한 · 판정 구간 · 전력량요금 |
| 요금 구성 (좌) | 기본요금 → 전력량요금 → 기후환경요금 → 연료비조정요금 → 전기요금(할인 전) |
| 할인 · 세금 (우) | 복지할인요금(한도 산식) → 하계/동계 할인 → 전기요금계 → 부가가치세 → 전력기금 → **청구금액** → 원단위 절사 |

입력 항목은 **4개뿐**이다.

| 입력 항목 | 쓰임 |
|-----------|------|
| 요금월 | `YYYY-MM`. 사용기간이 여기서 유도된다 |
| 사용량(kWh) | 요금 계산의 유일한 입력값 |
| 하계/동계 할인 | 할인액을 **양수로** 입력한다. 입력칸 앞의 `−` 기호로 차감임을 표시하고 저장 시 음수로 바꾼다 |
| 장애인 복지할인 적용 | 체크박스, **기본 체크**. 해제하면 복지할인 0원 |

**사용기간은 입력하지 않는다** — 검침일이 항상 21일이라 요금월에서 유도한다
(`2026-07` → `2026-06-22 ~ 2026-07-21`).

목록 컬럼은 **요금월 · 사용량 · 복지할인 · 하계/동계 할인 · 청구요금**이다.
사용기간·전력량요금 등 나머지는 우측 상세 패널에서 본다.

### 2. 일별 사용량

선택한 요금월의 사용기간을 날짜 행으로 펼쳐 매일 확인한 사용량을 입력한다.

```
사용기간 2026.07.22 ~ 2026.08.21     [합계를 청구 사용량으로 반영]
─────────────────────────────────────────────────────
  합계        목표        잔여량      일평균 · 예상
  297.8    [ 300 ]         2.2        9.9 · 307.9
            ↑ 직접 수정 (비우면 구간 경계 자동)
─────────────────────────────────────────────────────
  일    월    화    수    목    금    토
              22    23    24    25    26
             7.2   9.0   9.3  13.0  11.5
  27    28    29    30    31   8월1    2
11.1  11.0   9.5   9.6   7.6   4.8   5.0
   3     4     5     6     7     8     9
12.8 ▒29.9  12.9 ▒25.6 ▒20.5  12.0  10.5
```

**사용기간을 요일에 맞춘 달력**으로 배치한다. 두 달에 걸치므로 월이 바뀌는 1일 칸에는
`8월` 표시를 붙인다.

| 표시 | 의미 |
|------|------|
| 일요일 빨강 / 토요일 파랑 | 요일 구분 |
| 노란 배경 | 일평균의 1.5배를 넘는 날 — 과사용 확인용 |
| 점선 테두리 | 아직 입력하지 않은 날 |

- 값을 지우면 해당 일자 기록이 삭제된다 (미입력 상태)
- 잔여량이 음수가 되면(목표 초과) 붉게 표시
- 일평균과 남은 일수로 **예상 최종 사용량**을 함께 보여준다
- **목표 사용량은 이 탭에서 수정한다.** 잔여량을 보면서 조정하는 게 자연스러워
  청구 입력 팝업에서는 뺐다. 비우면 안분된 1구간 상한으로 되돌아간다

### 3. 요금표 관리

한전 인상에 대응해 요금표를 적용시작일 단위로 관리한다.

입력 화면은 **한전 요금표와 같은 표 형태**다. 구간·기본요금·단가의 관계가 한 줄로 읽힌다.

```
적용 시작일 [2026-01-22]        계절 [기타계절 ▼]
검침일이 이 날짜 이후인 청구부터   여름·기타계절 두 행이 한 쌍

누진 구간별 요금
┌────────┬──────────────┬────────────┬──────────────┐
│ 구간   │ 사용량 상한   │ 기본요금    │ 전력량 단가   │
├────────┼──────────────┼────────────┼──────────────┤
│ 1구간  │ [ 200 ] kWh  │ [  730 ]원 │ [   105 ]원  │
│        │ 0 ~ 200      │            │              │
│ 2구간  │ [ 400 ] kWh  │ [1,260 ]원 │ [   174 ]원  │
│        │ 201 ~ 400    │            │              │
│ 3구간  │ 401 ~ 무제한  │ [6,060 ]원 │ [ 242.3 ]원  │
└────────┴──────────────┴────────────┴──────────────┘
한전 기준 — 여름 300 / 450, 기타계절 200 / 400

공통 단가
복지할인 한도 [16,000]원  기후환경요금 [9]원/kWh  연료비조정 [5]원/kWh
전력기금률 [2.7]%         부가세율 [10]%
```

- **사용량 상한은 누적값으로 입력**한다(200 / 400). DB는 구간 폭(200/200)으로 저장하므로
  저장할 때 변환하고, 입력 중에는 `0 ~ 200` · `201 ~ 400` 처럼 실제 범위를 아래에 보여준다
- 2구간 상한이 1구간보다 작으면 범위 표시가 빨갛게 되고 저장이 막힌다

여름·기타 두 행이 한 쌍이며, 인상 시 새 적용시작일로 두 행을 추가한다.
과거 청구서는 그때의 요금표로 계산되므로 값이 바뀌지 않는다.

---

## 계산 규칙 요약

- **계절 경계를 걸친 달은 일수로 안분**한다. 사용량·구간상한·기본요금 모두 안분 대상 (한전 방식)
- 복지(장애인)할인은 한도액도 일수 안분하고, `-min(전기요금, 한도)` 로 적용
- 부가세는 반올림, 전력기금과 청구요금은 10원 절사

자세한 산식과 검증 결과는 [power_task.md](power_task.md) 참고.
