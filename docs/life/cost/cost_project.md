# 생활비 관리 (`/life/cost`)

## 개요

월별 생활비·고정지출·카드결제를 항목별로 입력·관리하는 개인 가계부 화면.
`/life` 접근 시 `/life/cost`로 자동 리다이렉트.

---

## 화면 구조

### 레이아웃 (2-column)

```
┌─────────────────────┐  ┌──────────────────────────────────────────────────┐
│  월 선택 드롭다운    │  │  고정지출                           [+ 항목추가] │
│  수입 대비 지출 현황 │  │  고정이체 & 금융                    [+ 항목추가] │
│  주요 지출 TOP 3     │  │  생활비 & 공과금  [탭: 건물명 선택] [+ 항목추가] │
│  최근 3개월 현황     │  │  카드결재                           [+ 항목추가] │
└─────────────────────┘  └──────────────────────────────────────────────────┘
```

### 왼쪽 패널

| 섹션 | 내용 |
|------|------|
| 월 선택 | YYYY-MM 드롭다운, 기본값 당월 |
| 수입 대비 지출 현황 | 수입 / 지출(청구·현금 소계) / 잔액(색상 구분). **카드 사용액은 다음 달 청구되므로 지출에서 제외**하고 아래에 참고값으로 별도 표시 |
| 주요 지출 TOP 3 | 당월 금액 기준 상위 3개 + 전월 대비 변동(↑/↓/±0) |
| 최근 3개월 현황 | 월·수입·지출 3행 테이블 |

### 오른쪽 패널

| 섹션 | 내용 |
|------|------|
| 고정지출 | 항목명 hover→툴팁, 날짜, 결제수단(카드 결제 항목은 **연결된 카드명**을 배지로 표시 — 항목 관리 팝업과 같은 기준), 금액, 메모, 편집 |
| 고정이체 & 금융 | 항목명(계좌번호 툴팁), 날짜, 금액 |
| 생활비 & 공과금 | sub_category 탭(건물별), 항목 목록 |
| 신용카드 | 카드명, 결제금액, 전월대비, 결제일, 정산기간 — 카드명·결제일·정산기간은 `my_card`에서 JOIN (체크카드는 결제일 "즉시") |

## 주요 UX

| 동작 | 설명 |
|------|------|
| 금액·메모 수정 | 금액/메모 셀(또는 행 아무 곳) 클릭 → 행 편집 모드. 금액·메모를 동시에 편집하며 클릭한 셀에 포커스(금액은 기존 값 전체 선택, 입력 시 천단위 콤마 자동), Tab으로 금액↔메모 이동 |
| 편집 확정 | ✕ 버튼 왼쪽의 `[적용]` 또는 Enter → `upsertCostInfo` 저장. `[취소]`/Esc → 원래 값 복원. **blur 자동 저장 없음** (편집 가능 셀은 hover 시 파란 테두리 표시) |
| 항목 추가 | [+ 항목추가] 버튼 → 모달 |
| 월 데이터 삭제 | 월별 표의 행 ✕ → 해당 월 `my_cost_info` 행만 DELETE (항목 마스터·다른 월 데이터는 유지, [+ 항목추가]로 재등록 가능) |
| 항목 비활성화 | 입출금 항목 관리 모달에서 `use_yn='N'` — 기록을 남기고 목록에서만 숨김 |
| 항목 삭제 | 관리 모달의 `[삭제]` — 항목 마스터와 월별 실적을 함께 제거. 실적이 있으면 확인창에 건수·기간을 명시하고, 쇼핑 구매 내역이 참조 중이면 버튼을 비활성화한다. 되돌릴 수 없으므로 일시적으로 안 쓰는 항목은 비활성화를 쓴다 |
| 결제수단 선택 | 항목 추가·수정 모달의 결제수단 드롭다운에 `현금` / 등록된 카드 목록 / `카드(미지정)` 을 한 번에 표시. 카드를 고르면 `cost_type='2'` + `card_id` 가 함께 저장돼 "카드인데 카드 미선택" 상태가 생기지 않는다 |
| 카드 연결 | 카테고리가 신용카드(`4`)면 결제수단에는 카드를 노출하지 않고(카드 대금은 계좌 출금) 별도 "연결 카드" 드롭다운으로 `my_card` 를 연결 |
| 카드 상세 관리 | 항목 관리 모달 상단 `[입출금 항목 추가]` 오른쪽의 `[카드 정보]` → 카드 목록 모달(`my_card` 전체) → 행의 `[수정]` → 카드 상세 모달. 카드명·구분·결제일·정산기간·메모 편집, 카드번호는 뒤 4자리만 표시, 유효기간·CVC는 마스킹 후 `[보기]` 클릭 시 서버에서 복호화 |
| 월 초기화 | 신규 월 첫 접근 시 "이전 달 복사" 버튼 → default_amount 기준 일괄 생성 |
| 잔액 색상 | 잔액 ≥ 0 → 파란색, 잔액 < 0 → 빨간색 |
| 툴팁 | 모든 항목 행 hover 시 상세 정보 표시 |
