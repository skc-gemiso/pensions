# 개인연금 — 프로젝트 개요

## 개요

연금저축펀드 계좌 하나를 재원으로, **지금 이대로 적립하면 수령 개시 나이에 매달 얼마를 받는지**
보여주는 화면. 원금을 헐지 않고 커버드콜 ETF 분배금만 받는 구조를 전제로 한다.

- 경로: `/pension/per`
- 상태: **구현 완료**
- 재원: `201-04-931585` (NH 연금저축펀드) / `498400` KODEX 200타겟위클리커버드콜 / 월 50만원 수동 매수
- IRP·ISA 는 투자 계획이 없어 다루지 않는다
- 참고 파일: [app/pension/per/page.tsx](../../../app/pension/per/page.tsx),
  [app/pension/per/actions.ts](../../../app/pension/per/actions.ts),
  [lib/pension-per-calc.ts](../../../lib/pension-per-calc.ts)

## 화면 구조

```
/pension/per
├── 제목 + 도움말 ! (PageHelpModal)     계산 전제 / 산출 방법 / 한계와 주의
├── 계좌 현황
│   ├── 보유수량 · 평가액 · 매입금액 · 평가손익
│   ├── 주가 / 월 분배율(연환산) / 주당 월 분배금(예상)
│   └── 누적 수령 분배금 → 클릭 시 지급 이력 팝업 (실적치)
├── 적립 계획 확인 (읽기 전용 — 값의 출처는 config/.env)
├── 계획 요약 카드
│   ├── 적립  지금 ~ 정년        월 적립액 + 분배금 재투자
│   ├── 거치  정년 ~ 수령개시     분배금만 재투자
│   └── 수령  수령개시 ~          분배금 수령 (수량 고정)
├── 퇴직 시점별 비교  [예상치] [읽는 법 → RetireCompareHelp]
├── 연도별 추이       [예상치] [읽는 법 → YearlyTrendHelp]
└── 빠른 이동
    ├── 연금저축펀드 시뮬레이션 → /sim
    └── 복리의 마법 → /magic
```

`적립 계획 확인` 팝업은 **읽기 전용**이다. 생년월일·입사일·정년과 수령 나이·월 적립액은
`config/.env` 에서 관리하므로, 팝업은 현재 값과 대응하는 환경 변수명만 보여준다.
개인 정보는 퇴직연금 화면도 같은 값을 쓴다.

## 실적치와 예상치의 구분

이 화면에서 가장 중요한 UI 원칙이다. 미래 숫자가 확정 금액으로 읽히면 안 된다.

| 구분 | 항목 | 표기 |
|------|------|------|
| 실적치 | 보유수량, 평가액, 매입금액, 손익, 누적 수령 분배금 | 그대로 표시 |
| 예상치 | 주당 월 분배금, 월 수령액, 퇴직 시점별 비교, 연도별 추이 | `예상치` 앰버 배지 + 전용 도움말 |

- 누적 수령 분배금은 시뮬레이션이 아니라 `t_etf_dividend` 지급 이력 기반이므로
  클릭하면 지급기준일별 상세 목록이 열린다
- 표마다 전용 도움말을 둬서 컬럼의 뜻·읽는 요령·깔린 가정을 따로 설명한다
  (`/sim` 의 ETF 설명 팝오버와 같은 결)

## 핵심 개념

### 왜 주가를 올리지 않는가

커버드콜 ETF 는 주가 상승분을 옵션으로 팔아 분배금으로 돌려주는 구조다.
장기적으로 주가는 크게 오르지 않고 분배금이 수익의 대부분을 차지하므로,
주가를 현재가로 고정하는 편이 실제에 가깝고 결과도 보수적으로 나온다.

### 계좌 유형별 세제 혜택 (참고)

| 계좌 | 납입 한도 | 세제 혜택 |
|------|-----------|-----------|
| 연금저축펀드 | 연 600만원 | 세액공제 13.2%~16.5% (총급여 5,500만원 기준) |
| IRP | 연금저축 포함 연 900만원 | 세액공제 동일 + 퇴직금 이전 |
| ISA | 연 2,000만원 (5년 누적 1억) | 200만원(서민 400만원) 비과세 / 초과분 9.9% 분리과세 |
