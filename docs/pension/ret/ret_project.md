# 퇴직연금 — 프로젝트 개요

## 개요

퇴직소득세(2023년 개정 기준)를 포함한 퇴직금 예상 계산과,
그 퇴직금을 커버드콜 ETF 로 운용했을 때의 분배금 시뮬레이션을 제공하는 화면.

- 경로: `/pension/ret`
- 상태: **완전 구현**
- 참고 파일: [app/pension/ret/page.tsx](../../app/pension/ret/page.tsx)

## 핵심 개념

### 퇴직소득세 계산 (2023년 개정)

- 근속 연수 공제: 근속 기간에 따라 과세표준에서 공제
- 환산 급여 방식: 퇴직금을 근속 연수로 나눠 12를 곱하는 환산 급여 계산
- 세율 구간: 환산 급여 기준 누진세율 적용
- 최종 퇴직소득세 = 환산 세액 ÷ 12 × 근속 연수

### 퇴직금 커버드콜 운용 시뮬레이션

- **IRP·ISA 로 이전하지 않는다.** 퇴직소득세 실효세율이 근속연수공제 덕에 이미 낮아
  (근속 15년 약 3.9%, 정년 19년 약 3.6%), 이연·감면으로 아끼는 세금보다 IRP 의
  운용 제약·인출 절차가 더 번거롭다고 보고 **일시금 수령 후 일반 계좌 운용**을 기준으로 잡았다
- 포트폴리오: KODEX 200 타겟위클리커버드콜 100%
- 분배율: 하드코딩하지 않고 `t_etf_dividend` 최근 12회 평균에서 구한다 —
  개인연금(`/pension/per`) 화면과 같은 기준
- 세금: **계산에 넣지 않는다.** 커버드콜 분배금은 대부분 파생상품 매매이익이라
  실제 과세 대상(과세표준액)이 분배금의 4~5%뿐이고, 배당소득세 15.4%를 거기에만 매기므로
  실효세율이 1%에 못 미친다. 금융소득종합과세도 연 분배금이 약 4.8억이어야 걸려 사실상 무관하다
- 원금(수량)은 헐지 않고 분배금만 받는 구조
- **시나리오는 하나뿐이다** — 매입 → 63세(2037.06)까지 분배금 전액 재투자 → 그 뒤부터 분배금만 수령.
  주가는 현재가 고정(상승률 0%)이라 평가액은 재투자한 만큼만 늘어난다
- **매입 시점 = 퇴직 시점** — DB형(확정급여형)이라 퇴직 전에는 회사가 적립금을 운용하므로
  개인이 손댈 수 없고, 그 전에 발생하는 분배금도 없다
- **만 55세(2029.06) 이전 퇴직은 표에서 제외한다.** 퇴직급여가 IRP 로 의무 이전되고
  만 55세까지 인출할 수 없는데 IRP 를 운용하지 않는다는 전제라 시나리오가 성립하지 않는다.
  위쪽 `퇴직 시점별 예상 퇴직금` 표에는 그 연도들이 그대로 남아 있다 —
  퇴직금을 받는 것 자체는 성립하기 때문이다

> 실효세율은 화면에서 하드코딩하지 않고 `taxRateAt(근속연수)` 로 표의 행에서 뽑아 쓴다
> (`taxMan / grossMan`). 퇴직금 추정치가 바뀌면 문구의 세율도 함께 따라간다.

## 변경 이력

| 시점 | 내용 |
|------|------|
| 초기 구현 | 퇴직소득세 계산 + 연도별 퇴직금 테이블 완성 |
| 개선 | IRP 배당 시뮬레이션 테이블 추가 |
| v028 | 입사일·정년을 공통 프로필에서 조회. 정년이 입사 기념일(2034.02)로 잘못 잡혀 있던 것을 정년 규정(만 60세가 되는 달의 말일, 2034.06)으로 수정 |
| — | 공통 프로필의 저장소를 `my_profile` 테이블에서 `PROFILE_*` 환경 변수로 이전 |
| — | IRP 포트폴리오(커버드콜 70% + TDF 30%) 시뮬레이션을 **커버드콜 100%** 기준으로 교체. IRP·ISA 미운용 방침 반영, 분배율을 실제 지급 이력에서 조회하도록 변경 |
| — | 과세 기준을 분배금 전액 → **과세표준액**(분배금의 약 4~5%)으로 수정. 종합과세 판정도 같은 기준으로 변경 |
| — | 63세까지 재투자 후 수령하는 시나리오를 같은 표에 2단 헤더로 추가. DB형이라 재투자 시작은 퇴직 연도가 아니라 **정년 시점**으로 고정 |
| — | DB형은 정년 전 ETF 매입 자체가 불가능하므로 `퇴직 직후부터 수령` 시나리오를 삭제. **정년 매입 → 63세까지 재투자 → 63세부터 수령** 단일 구조로 정리 |
| — | 페이지·카드별 도움말 추가. 개인연금과 중복되던 모달 껍데기를 `components/HelpModal.tsx` 로 공용화 |
| — | 매입 시점 기준을 정년 → **max(퇴직 시점, 만 55세)** 로 변경. 만 55세부터 퇴직연금을 개인이 운용할 수 있다 |
| — | 분배금 과세·과표 항목 전면 삭제. 실효세율 1% 미만이라 표만 복잡해졌다 |
| — | 만 55세 이전 퇴직 행을 시뮬레이션 표에서 **제외**. IRP 의무 이전으로 인출이 막혀 시나리오가 성립하지 않는다. 매입 시점은 `max(퇴직, 만 55세)` → `퇴직 시점` 으로 단순화 |
| — | 표 하단 주석과 `계산 가정 및 주의사항` 카드를 삭제하고 내용을 도움말로 통합. 본문에는 한 줄 요약만 남긴다 |
| — | IRP 미이전 근거를 "운용 계획 없음"에서 **퇴직소득세 실효세율이 낮다**로 교체. 세율은 표에서 계산해 표시 |
