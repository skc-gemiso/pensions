# 나의 연금 현황 — 프로젝트 개요

## 개요

국민연금·퇴직연금·개인연금 **세 연금의 월 수령액을 같은 축에 놓아** 노후 소득을
한 화면에서 파악하는 통합 대시보드.

단순 네비게이션 허브였으나, 각 연금의 실제 데이터를 합산해 **수령 시점별 월 소득**을
보여주는 화면으로 바꿨다. 개시 나이가 서로 달라서 합계만으로는 실제 흐름이 보이지 않는다.

- 경로: `/pension/my` (`/pension` 진입 시 자동 리다이렉트)
- 상태: **구현 완료**
- 참고 파일: [app/pension/my/page.tsx](../../../app/pension/my/page.tsx),
  [app/pension/my/actions.ts](../../../app/pension/my/actions.ts)

## 화면 구조

```
/pension/my  — 제목 옆 도움말 ! (무엇을 모았나 / 공통 전제 / ⚠️ 한계)
├── 요약 + 수령 시점별 (한 카드)
│   ├── [상단 1행] 합산 월 수령액 + 연 환산 / 먼저 받는 시점
│   ├── [상단 2행] 과거 추이 — 탭(3연금 합계 · 개인 · 퇴직 · 국민) + 월별 표 (증가·증가율)
│   └── [하단 회색면] 수령 시점별 연금 수령액 (범례에 비중 %)
│       ├── 63세부터 — 개인연금 + 퇴직연금 (스택 바)
│       └── 65세부터 — + 국민연금
├── 연금별 카드 3개 (클릭 시 각 화면으로)
│   ├── 개인연금  월 수령액 / 연금저축펀드 평가액 / 목표 대비 진행률
│   ├── 퇴직연금  월 수령액 / 현재 기준 실수령 퇴직금 / 근속 진행률
│   └── 국민연금  월 수령액 / 총 납부 보험료 / 납부 진행률
├── [참고] 퇴직금 중도인출 시나리오 — 도움말 ! (계산 방법 / 왜 늘어나나 / ⚠️ 한계)
│   └── 결론 2칸 + 두 몫 표(중도인출분 · 정년 추가분) + 총액 감소 문구
│       PENSION_RET_WITHDRAW_DATE 가 비면 카드 자체가 없다
└── [참고] 국민연금 조기수령 시나리오 — 도움말 ! (계산 방법 / 손익 계산 / ⚠️ 한계)
    └── 결론 2칸 + 시점별 흐름 표(적립기 · 수령기) + 소득 공백 경고
        PENSION_NAT_EARLY_YEARS 가 비면 카드 자체가 없다
```

참고 카드는 각각 독립이다. 하나를 꺼도 다른 하나는 그대로 나오고, 둘 다 **기준(현행 계산)과
비교**할 뿐 서로 합치지 않는다.

스택 바의 폭은 **구간 최대 합계 대비 비율**이라, 국민연금이 더해질 때 막대가 길어진다.

## 핵심 개념

### 개시 시점이 둘로 갈린다

| 시점 | 나이 | 시작하는 연금 |
|------|------|---------------|
| 2037.06 | 63세 | 개인연금 + 퇴직연금 (`PENSION_PER_PAYOUT_AGE` 공통) |
| 2039.06 | 65세 | + 국민연금 (1969년 이후 출생자 기준) |

정년(2034.06) 이후 63세까지는 **세 연금 모두 수령액이 없다.** 그 기간의 생활비는
이 화면이 다루지 않는다 — 도움말에 명시했다.

### 성격이 다른 값을 한 화면에 놓는다

| 연금 | 성격 | 근거 |
|------|------|------|
| 국민연금 | **실적 기반** | 공단 통보 예상 수령액(세후). 물가 연동 + 종신 |
| 퇴직연금 | 예상치 | 급여명세서 평균임금으로 추정한 정년 퇴직금을 커버드콜로 운용 |
| 개인연금 | 예상치 | 실제 보유수량 + 월 적립 + 분배금 재투자 |

금액은 국민연금이 가장 작지만 **확실성은 가장 높다.** 합계의 대부분이 커버드콜
분배금이라 분배율 가정이 흔들리면 합계도 같이 흔들린다 — 도움말 `⚠️ 한계` 탭에서 다룬다.

### 퇴직금은 손해, 수령액은 이득 (중도인출 시나리오)

2029.06 에 퇴직금을 중도인출하고 계속 재직하면 **퇴직금 총액은 1,342만원 줄어드는데
63세 월 수령액은 81% 늘어난다.** 인출분이 그 시점의 낮은 평균임금으로 정산되지만,
거치 기간이 36개월(×1.66) → 96개월(×3.88)로 늘어 복리가 그 손해를 압도하기 때문이다.

한쪽만 보여주면 오해를 부르므로 **카드에 둘 다 적는다.** DB형은 중도인출 규정 자체가
없어 성립하지 않을 수 있다는 점도 도움말에 명시했다.

### 조기수령의 진짜 비용은 물가 연동 (국민연금 시나리오)

국민연금을 5년 앞당기면 30% 평생 감액되지만, 앞당겨 받은 5년치를 커버드콜에 적립하면
65세부터 132만 → **216만원**이 된다. 감액분(월 40만)보다 분배금(월 124만)이 크기 때문이다.

다만 **국민연금은 물가에 연동돼 매년 오르고, 깎인 30%는 그 인상분에도 그대로 적용된다.**
ETF 분배금에는 물가 연동이 없다. 이 비교는 물가를 반영하지 않았으므로 오래 살수록
조기수령이 불리해진다 — 도움말에서 이 점을 다룬다.

또 만 60~63세는 개인·퇴직연금 개시 전이라 **세 연금 모두 수입이 0**이 된다.
그 기간 생활비가 따로 있어야 성립하는 시나리오다.

### 계산은 각 화면과 같은 모듈을 쓴다

값이 화면마다 어긋나지 않도록 계산을 공유한다.

| 대상 | 모듈 |
|------|------|
| 퇴직연금 | [lib/pension-ret-calc.ts](../../../lib/pension-ret-calc.ts) — 퇴직연금 화면과 공용 |
| 개인연금 | [lib/pension-per-calc.ts](../../../lib/pension-per-calc.ts) — 개인연금 화면과 공용 |
| 생년월일·정년 | [lib/profile.ts](../../../lib/profile.ts) + `PROFILE_*` 환경 변수 |
| 분배율 | `t_etf_dividend` 최근 12회 평균 (세 화면 공통) |

|------|------|

| — | 노령연금 카드 제거 (메뉴 삭제) |
| — | 디자인 시안 반영 — 원형 아이콘·색 언어 통일·수령 시점별 행 재구성. 시안은 다크였으나 라이트 테마 유지 |
| — | 요약과 수령 시점별을 **한 카드로 통합**. 하단 구역은 회색 면으로 구분 |
| — | 상단의 연금별 월 수령액이 스택 바·연금별 카드와 삼중 중복이라 걷어내고, 그 자리에 **월별 과거 추이**(스파크라인)를 넣음. 비중 %는 스택 바 범례로 이동 |
| — | 스파크라인이 점 3~4개짜리라 읽히지 않아 **연금 탭 + 월별 표**로 교체. 세 연금 모두 `월 수령액` 을 공통 축으로 두고 증가·증가율을 붙임 |
| — | **3연금 합계 탭**을 맨 앞에 추가(기본 탭). "지난달 얼마에서 이번달 얼마로 바뀌었나"가 이 화면의 본래 질문이라서. 국민연금은 확인 시점 사이를 보간해 합계를 성립시킴 |
| — | 하단에 **국민연금 조기수령 참고 카드** 추가 — 5년 앞당겨 30% 감액된 연금을 커버드콜에 적립하면 65세부터 132만 → **216만원**. `PENSION_NAT_EARLY_YEARS` 를 비우면 사라진다 |
| — | 하단에 **중도인출 참고 카드** 추가 — 2029.06 에 퇴직금을 인출하고 계속 재직하면 63세 월 수령액이 421만 → **764만원**. 기존 계산은 손대지 않는 별도 가정이고, `PENSION_RET_WITHDRAW_DATE` 를 비우면 사라진다 |
| — | 추이의 기준을 **"그 달에 이 화면을 봤다면 나왔을 값"** 하나로 통일. 퇴직연금을 근속 기반에서 **정년 기준**으로 되돌리고, 분배율도 그 달 시점의 12회 평균을 씀 → 각 탭의 최신 행이 아래 카드와 정확히 일치 |
| — | **통합 대시보드로 전환** — 세 연금 실데이터 합산, 수령 시점별 월 소득, 도움말 추가. 값이 낡아 있던 `NationalPensionDashboardCard`·`RetirementDashboardCard` 삭제 |

## To-Be 개선 방향

- 국민연금 스냅샷을 더 자주 기록 — 현재 4건뿐이라 합계 탭이 대부분 보간값에 기댄다
- 개인연금 이력이 2026.05부터라 합계 탭도 4개월뿐이다 — 달이 지나며 저절로 길어진다
- 정년~63세 공백 기간의 생활비 계획 반영
- 물가상승률을 반영한 실질 가치 표시
- 국민연금 조기수령·연기수령 시나리오 비교
- 건강보험료(피부양자 자격 상실) 영향 반영
