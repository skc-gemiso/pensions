# 나의 연금 현황 — 프로젝트 개요

## 개요

국민연금·퇴직연금·개인연금 **세 연금의 월 수령액을 같은 축에 놓아** 노후 소득을
한 화면에서 파악하는 통합 대시보드.

단순 네비게이션 허브였으나, 각 연금의 실제 데이터를 합산해 **수령 시점별 월 소득**을
보여주는 화면으로 바꿨다. 개시 나이가 서로 달라서 합계만으로는 실제 흐름이 보이지 않는다.

- 경로: `/pension/my` (`/pension` 진입 시 자동 리다이렉트)
- 상태: **구현 완료**
- 참고 파일: [app/pension/my/page.tsx](../../../app/pension/my/page.tsx),
  [app/pension/my/actions.ts](../../../app/pension/my/actions.ts)

---

## 화면 구조

```
/pension/my  — 제목 옆 도움말 ! (무엇을 모았나 / 공통 전제 / ⚠️ 한계)
├── 핵심 요약
│   ├── [그라디언트] 63세부터 세 연금 합산 월 수령액 + 연 환산 + 연금별 비중
│   └── 가장 먼저 받는 시점 / 지금까지 쌓은 금액 합계
├── 수령 시점별 월 소득
│   ├── 63세부터 — 개인연금 + 퇴직연금 (스택 바)
│   └── 65세부터 — + 국민연금
└── 연금별 카드 3개 (클릭 시 각 화면으로)
    ├── 개인연금  월 수령액 / 연금저축펀드 평가액 / 목표 대비 진행률
    ├── 퇴직연금  월 수령액 / 현재 기준 실수령 퇴직금 / 근속 진행률
    └── 국민연금  월 수령액 / 총 납부 보험료 / 납부 진행률
```

스택 바의 폭은 **구간 최대 합계 대비 비율**이라, 국민연금이 더해질 때 막대가 길어진다.

## 핵심 개념

### 개시 시점이 둘로 갈린다

| 시점 | 나이 | 시작하는 연금 |
|------|------|---------------|
| 2037.06 | 63세 | 개인연금 + 퇴직연금 (`PENSION_PER_PAYOUT_AGE` 공통) |
| 2039.06 | 65세 | + 국민연금 (1969년 이후 출생자 기준) |

정년(2034.06) 이후 63세까지는 **세 연금 모두 수령액이 없다.** 그 기간의 생활비는
이 화면이 다루지 않는다 — 도움말에 명시했다.

### 성격이 다른 값을 한 화면에 놓는다

| 연금 | 성격 | 근거 |
|------|------|------|
| 국민연금 | **실적 기반** | 공단 통보 예상 수령액(세후). 물가 연동 + 종신 |
| 퇴직연금 | 예상치 | 정년 퇴직금(회사 사전 계산값)을 커버드콜로 운용 |
| 개인연금 | 예상치 | 실제 보유수량 + 월 적립 + 분배금 재투자 |

금액은 국민연금이 가장 작지만 **확실성은 가장 높다.** 합계의 대부분이 커버드콜
분배금이라 분배율 가정이 흔들리면 합계도 같이 흔들린다 — 도움말 `⚠️ 한계` 탭에서 다룬다.

### 계산은 각 화면과 같은 모듈을 쓴다

값이 화면마다 어긋나지 않도록 계산을 공유한다.

| 대상 | 모듈 |
|------|------|
| 퇴직연금 | [lib/pension-ret-calc.ts](../../../lib/pension-ret-calc.ts) — 퇴직연금 화면과 공용 |
| 개인연금 | [lib/pension-per-calc.ts](../../../lib/pension-per-calc.ts) — 개인연금 화면과 공용 |
| 생년월일·정년 | [lib/profile.ts](../../../lib/profile.ts) + `PROFILE_*` 환경 변수 |
| 분배율 | `t_etf_dividend` 최근 12회 평균 (세 화면 공통) |
