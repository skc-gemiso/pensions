# 장암2구역 투자 현황 (`/invest/jangam2`)

## 목적

재개발(장암2구역) 조합원 분양을 받을 때 필요한 **분담금을 감당할 자금이 준비돼 있는지**를
한 화면에서 확인한다.

정비사업 진행 경과·종전자산 평가·평형별 분양 예정가는 몇 달에 한 번 바뀌는 문서성 데이터라
DB 테이블 대상이 아니다 (CLAUDE.md "테이블 생성 기준"). 데이터는 git 에 커밋되는
[data/jangam2.md](../../../data/jangam2.md) 한 파일로 관리한다.

## 화면 원칙

- **읽기 전용.** 등록·수정·삭제 UI 를 두지 않는다. 값 변경은 `data/jangam2.md` 를 직접 편집한다.
- MD 를 저장하고 브라우저를 새로고침하면 바로 반영된다 (파서가 요청마다 파일을 읽는다 — 서버 재시작 불필요).
- 주식 계좌 평가액만 예외로 **DB 실시간 조회**다 (`my_stock` · `t_stock_amt`).

## 화면 구조

| 행 | 좌 (4) | 우 (6) |
|----|----|----|
| 1 | 일반 현황 | 추진 경과 |
| 2 | 특화 품목 | 조합원 제공품 |
| 3 | 종전자산 평가 (일자별 이력) | 조합원 분양 예정가 (일자별 이력) |
| 4 | 추정 분담금 (최신 기준) — 전폭 | |
| 5 | 자금 준비 현황 — 전폭 | |

1~3행은 `lg:grid-cols-10` + `col-span-4` / `col-span-6` 로 **4 : 6 비율**이다.

### 카드별 기능

| 카드 | 설명 |
|------|------|
| 일반 현황 | 주소·정비구역 면적·조합원 수·건축 계획·시공사 등 (MD `- 키: 값` 목록 그대로) |
| 추진 경과 | 일자 내림차순 목록. 번호 배지 + `내용(3) : 일자(2) : 비고(5)`. **최근 5개만 보이고 나머지는 스크롤** (한 행 32px · `max-h-40`) |
| 특화 품목 | 단지 특화 항목 목록 |
| 조합원 제공품 | 가전·옵션 목록 (3열 그리드) |
| 종전자산 평가 | 일자별 평가금액·비례율·권리가액 이력. 최신 행이 계산 기준 |
| 조합원 분양 예정가 | 일자별 23·26·35·39·43평 예정가 이력. 최신 행이 계산 기준 |
| 추정 분담금 | 평형별 `최신 분양 예정가 − 최신 권리가액` (파생값, MD 에 적지 않는다) |
| 자금 준비 현황 | 평형별 필요 자금 = 추정 분담금 + 이자 비용(평형) − 주식 계좌 평가액 − 기타 준비 자금. 하단에 차감(준비 자금)·가산(이자 비용 `항목 × 평형`) 내역을 나란히 표시 |

## 자금 준비 현황

```
필요 자금(평형)
  = 조합원 분양 예정가(평형, 최신 일자)
  − 권리가액(최신 일자 종전자산 평가)
  + 이자 비용(평형)         ← MD (계약/중도금 이자 · 이주비 대여금 이자 · 기타 이자 — 평형별)
  − 주식 계좌 평가액        ← MD 에 적은 계좌번호로 DB 실시간 조회
  − 기타 준비 자금 합계      ← MD
```

- 양수면 **부족**(빨강), 0 이하면 **충족**(파랑) — `docs/main_design.md` 색상 코딩 기준.
- 분양 예정가가 비어 있는 평형(예: 39평 미정)은 `-` 로 표시하고 계산에서 제외한다.
- 기준 일자는 카드 부제로 적지 않는다 — 종전자산 평가·분양 예정가 표에서 `최신` 배지가 붙은 행이 곧 기준이고,
  자세한 산식은 카드 제목 옆 도움말(`?`)에 있다.

## 접근 권한

`admin` 전용. 메뉴는 `투자 > 장암2구역 투자 현황` (`app_menus.id = 'jangam2'`, `parent_id = 'invest'`, `sort_order = 40`).
`주식 투자`(sort_order 30) 다음에 형제로 놓는다 — `stock` 을 부모로 삼으면
`AppLayout` 의 `buildNavTree` 규칙상 `주식 투자` 가 클릭 불가한 그룹 헤더가 되기 때문이다.

## 개선 방향

- 분담금 납부 일정(계약금·중도금·잔금)이 확정되면 시점별 자금 소요 타임라인 추가
- 취득세 등 이자 외의 **추가 비용**이 필요해지면 `## 이자 비용` 과 같은 `항목 × 평형` 형태로 섹션을 하나 더 두고 `+` 로 반영
- 예수금(`my_account_info` 입출금 잔액)까지 준비 자금에 포함할지 검토
